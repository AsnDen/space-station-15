# Стиль кода

## Java Style

- Используй Java 21.
- Делай helpers `private` или package-private, если не нужен публичный доступ.
- Registry ids: lowercase snake_case.
- Константы: `UPPER_SNAKE_CASE`.
- Идентефикаторы мода должны идти через `SpaceStation.MOD_ID`.
- Лучше маленькие category registries, чем один огромный смешанный файл.

## Fabric Patterns

- Server authority остается на сервере.
- Клиентный код должен быть в `src/client/java`.
- Packet codecs нужно регистрировать до отправки пакетов.
- Не загружать client-only классы из common/server кода.
- Для рецептов, лут тейблов, ворлдгена и химии по возможности использовать data-driven JSON.

## Checklist добавления контента

Для предмета:

- Регистрация в Джаве.
- Предмет в креативном меню.
- JSON модельки.
- Текстура.
- Русский/Английский переводы.
- Рецепт, лут-дата при необходимости.

Для блока:

- Регистрация в Джаве.
- `BlockItem` для отображения айтема в руке.
- Предмет в креативном меню.
- Blockstate JSON.
- Model JSON.
- Item model JSON.
- Текстура.
- Лут Тейбл.
- Mineable/tool тэги при необходимости.
- Русский/Английский переводы.

## Комментарии

Новые комментарии должны быть UTF-8 и короткими. Лучше объяснять, зачем код существует, чем пересказывать очевидное.

## Проверка

Минимум:

```bash
./gradlew build
```

Для gameplay-изменений также надо запускать клиент и проверять фичу в игре.
