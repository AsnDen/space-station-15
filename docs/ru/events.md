# События и таймеры

## Server Tick Event

`SpaceStation.onInitialize()` регистрирует `ServerTickEvents.END_SERVER_TICK`. Каждый server tick он проходит по online players и вызывает:

```java
ActionTimer.tick(player);
```

## ActionTimer

`ActionTimer` хранит активные действия по UUID игрока. Каждое действие содержит:

- Позицию целевого блока.
- Стартовую позицию игрока.
- Общее число тиков.
- Оставшиеся тики.
- Коллбэк по завершению.
- Флаг disassembly.

Таймер отменяется, если игрок ушел дальше чем на `0.2` блока от стартовой позиции. При завершении выполняется коллбэк и отправляется завершающий пакет.

## Timer HUD

`TimerHud` существует только на клиенте. Он слушает пакеты таймера и рисует прогресс-бар внизу экрана:

- Синий: сборка.
- Оранжевый: разборка.
- Зеленая вспышка: завершено.
- Красная вспышка: отменено.

## Loot Table Events

`ModLootModifiers.register()` использует `LootTableEvents.MODIFY`, чтобы добавить семена растений в ванильные лут тейблы.

Хелпер `addSeedLoot(...)` получает карту групп лут тейблов к значениям шанса и добавляет предмет, если текущая таблица совпадает.

## Как добавить новое действие с таймером

Используй `ActionTimer.start(...)` из server-side кода. В `completion callback` нужно повторно проверить важные условия перед изменением мира или инвентаря, потому что состояние могло измениться за время таймера.
